## Server spell routing (`server/src/state/modules/`)

| Module | Owns |
| --- | --- |
| `namedSpellsCastThisGame.ts` | `persistNamedSpellCastThisGame` — this-game named-cast ledger. Shared by `recordSpellCastThisTurn`, GY/castSpell replay, `copyStackItem`, live/IR/delayed stack copies, and replay copy-resolve events that create a new copy. Do not call from a path that already records via `recordSpellCastThisTurn`, or from retarget-only / ability-copy paths. |
| `stackResolveSpellUncategorizedUtils.ts` | Uncategorized instant/sorcery IR fallback. Deleted `resolveSpell` ops (`DESTROY_ALL`, `DRAW_CARDS`, …) still categorize when `ORACLE_IR_SPELL_PRIMARY=0`; fallback must apply those IR steps or the spell no-ops. Entry: `tryApplyInstantSorceryUncategorizedSpellFallback`. |
| `stackResolveSpellZoneUtils.ts` | `tryResolveApproachOfTheSecondSunAfterEffects` no-ops when `isOracleIrSpellPrimaryEnabled()`. PRIMARY=0 trampolines the same IR win / seventh-from-top / life path (generic named-this-game, not `approachCastHistory`). |
| `stackResolveSpellSpecialCaseUtils.ts` | Phase 4 leftover special-cases. PRIMARY=0 trampolines Rite / Divine / Prisoner / Summons / Nibelheim to IR. Divine/Prisoner prompt queue lives in `oracleIrServerChooseDestroyRestSecretDamagePrompts.ts` (IR choice-family calls it directly). PRIMARY=1 special-case is a no-op (Rite window persist + Summons mill/token mutations come from live IR). |
| `applyEventResolveSpellDeletedOpEffects.ts` | Extracted from `applyEvent.ts`. Replay/`applyEvent({ type: 'resolveSpell' })` still carries deleted categorize specs; `resolveSpell()` returns []. Rebuilds `DamagePlayer`/`DamagePermanent` so Mindskinner replacements still apply. Entry: `effectsFromDeletedResolveSpellSpec`. |
| `oracleIrContinuationBridge.ts` | Leftover IR steps are bridged only by `oracleIrPendingResumeStepsJson` or a queued prompt that carries resume/choice JSON (`oracleIrResumeStepsJson`, `oracleIrChoiceStepJson`, Warp World choice, `oracleIrUnlessPayChoice`). Shock / check-land / as-enters copy/color / land-entry `sacrificeUnlessPayChoice` are not owners. Entries: `isOracleIrContinuationBridged`, `queuedStepOwnsOracleIrContinuation`. Used by persist and all-or-nothing (`oracleIrStepWiring.ts`). |
| `oracleIrServerChooseNumberPrompts.ts` | Queue `X_VALUE_SELECTION` for IR `choose_number` (Yusri 1–5). Entry: `queueChooseNumberPromptsFromOracleIRResult`. |
| `zones-handlers/zonesMovePermanentToLibrary.ts` | Recalculate extra land plays after LTB to library (shuffle/top/bottom), matching graveyard LTB. |

| `commanderExileFollowup.ts` | Infer `linkedExileData` / `flickerReturnData` for deferred commander exile choices from source oracle, unique linked-exile permanents, or pending return steps. |
| `triggerKeywordFallbackUtils.ts` | Isolated effect clauses still skip unrelated static keywords (Prowess). If the clause is the expanded text of a card keyword (Soulshift → return a Spirit), or is only an event stub (`enters the battlefield`), that keyword path still runs. |
| `triggerLifeDamageUtils.ts` | Generic `deals N damage to each opponent` (`tryApplyEachOpponentDamageTrigger`) and `deals N damage to target / any target / that player` (`tryApplyTargetedDamageFromEffectText`). Targeted path marks `damageThisTurn` on permanents and queues `deals_damage` player triggers. Used from executeTriggerEffect and the IR trigger fallback when `ORACLE_IR_TRIGGER_PRIMARY=0`. |
| `oracleIrPostApplyTriggerEmission.ts` | After IR `deal_damage` life loss, record `damageTakenThisTurnByPlayer` and queue source `deals_damage` player triggers (`queueDealsDamageToPlayerTriggersFromPermanent`). After IR `mill`, apply Eldrazi / Gaea's Blessing GY-shuffle triggers then emit `processMillTriggers` for new non-hand graveyard cards. |
| `triggerOracleIrTokenEtbBridge.ts` | After IR `create_token`, apply GY-source type-entry +1/+1 (Dearly Departed), then `triggerETBEffectsForPermanent` plus `queueTokenCreatedTriggers` (IR stamps tokens without the legacy `createToken()` path). |
| `triggerOracleIrPermanentEtbBridge.ts` | After IR `search_library` / `move_zone` puts a non-token onto the battlefield (`createBattlefieldPermanentsFromCards`), call `triggerETBEffectsForPermanent`. Tokens stay on the token bridge. Entry: `bridgeEnteredPermanentEtbTriggersAfterOracleIR`. |
| `oracleIrBattlefieldEntryPrompts.ts` | After IR stamps a new permanent, apply as-enters replacements the play-land path already has: shock pay-2-life, check/reveal tap, sacrifice-unless-pay (PRIMARY=0 only — trigger IR owns the prompt when PRIMARY=1), color/copy/type/player choice, plus GY-source type-entry +1/+1 (Dearly Departed). Also runs `applyAsEntersAutomaticReplacementsAfterOracleIR` (Ixidron face-down) before the prompt loop. Runs before the ETB bridge, including while Warp World / Thieves' Auction hold when-enters triggers. Entry: `queueBattlefieldEntryReplacementPromptsAfterOracleIR`. |
| `oracleIrBattlefieldEntryAutomaticReplacements.ts` | Automatic (non-prompt) as-enters replacements for IR-stamped permanents: `checkPermanentEntersTapped` plus `evaluateBattlefieldEntryReplacementEvent` metadata. Crash-safe wrapper so a missing helper cannot kill the process. Entries: `applyAsEntersAutomaticReplacementsForPermanent`, `tryApplyAsEntersAutomaticReplacementsForPermanent`. |
| `oracleIrAsEntersAutomaticReplacements.ts` | Apply IR as-enters automatic replacements (`turn_face_down`) via `applyOracleIRStepsToGameState` (not `applyOracleIRStepsOnServer`). Called from battlefield-entry prompts and permanent-spell post-entry. Entries: `applyAsEntersAutomaticReplacementsForPermanent`, `applyAsEntersAutomaticReplacementsAfterOracleIR`. |
| `oracleIrTriggerExecution.ts` / `triggerCastSpellStackBinding.ts` | Bind trigger `effectData.lifePaid` into IR `referenceAmount` after `lifeLost` so “put that many … counters” (Font of Agonies) resolves the paid amount. Spell-cast triggers bind the triggering stack spell into `targetSpellId` / `referenceSpellTypes` so “that player exiles it” and “shares a card type with it” (Possibility Storm) apply even when live persist omitted `triggeringStackItemId`. Discover X where X is that spell's mana value also stamps `spellManaValue` / `xValue` from the triggering stack spell (Monstrous Vortex family). Zero-mana intervening-if (`no mana was spent to cast it`) stamps `noManaSpentToCast` from that stack item’s `manaSpentTotal`. Once a trigger has a stack-item id, card id, name, or `triggeringSpellStackItem` snapshot, `findTriggeringSpellOnStack` never rebinds to a different live spell (Hive Mind / Possibility Storm last-known). Zero-identity G1 recovery still uses the unique/topmost remaining caster spell. Copy/ability paths use `resolveLiveOrLastKnownStackItem` instead of a name search. Entries: `findTriggeringSpellOnStack`, `cloneTriggeringStackItemSnapshot`, `readTriggeringStackItemSnapshot`, `resolveLiveOrLastKnownStackItem`. |
| `asEntersChoiceRequirements.ts` | IR `choose_*` as-enters prompts (color, creature type, basic land type, card name, player). Also reads `grant_static_ability` “may enter as a copy of any land/creature” (Vesuva / Clone) and as-enters `gain_control` “enters under the control of an opponent of your choice” (`appliesControlChange`). |

| `triggered-abilities.ts` / `triggers/zone-changes.ts` | Self-ETB `detectETBTriggers` marks `mandatory: false` when the effect includes “you may” (Knight of the White Orchid land search). Live detector is `triggers/etb-detection.ts` (re-exported through zone-changes + leftover). | `oracleIrAbilityExecution.ts` (`tryApplyStationChargeCountersViaOracleIR`) | If IR mutates charge counters but all-or-nothing reports unhandled (or throws after the mutation), treat the mutation as handled so the legacy station path does not add the same counters again. |
